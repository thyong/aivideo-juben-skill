# Adaptation contract

## Preserve story function, not surface wording

A valid rewrite changes the story carrier while retaining the core experience the user approved. Identify and lock:

- opening problem or hook;
- audience attachment target;
- primary emotional direction;
- cause-and-effect spine;
- escalation mechanism;
- climax and final payoff.

Do not reduce a rewrite to changing names, colors, species, foods, or occupations. Surface substitutions are valid only when the surrounding event chain is also rebuilt coherently.

## Supported adaptation types

### Character-function change

Changing `mother betrays -> father betrays` affects the actor, partner, witness, victim, confrontation, punishment, relationship text, pronouns, clothing, action, gaze, and dialogue. Update every affected occurrence.

### Prop change

Changing `strawberry -> tomato` may affect consumption/source, production, recognition, container, collection, transport, buyer, market type, sale, and final use. Preserve functional compatibility; do not select a replacement that makes the approved event chain implausible or visually unreadable.

### Event-carrier change

Changing `brick hauling -> sewer repair` affects the work request, workplace, clothing, tools, physical action, dirt/wet state, completion evidence, and payment. Preserve the event's story function, such as hardship, effort, income, rescue, discovery, or punishment.

### Combined change

Change several layers only when their dependencies remain simple enough for silent viewing. A medium combined rewrite is the default only when the user delegates the choice after seeing the proposed directions.

## Propagation closure

For each approved change, trace its full dependency chain:

- character: identity -> relationship -> action owner -> affected character -> emotion -> confrontation -> outcome;
- prop: source -> use -> state -> container -> transport -> destination/buyer -> value/result;
- occupation/event: trigger -> location -> clothing/tool -> action -> visible completion -> payment/consequence;
- location: function -> architecture -> recurring elements -> time/weather -> later recurrence.

A shot plan is incomplete if it changes the first link but leaves incompatible downstream links unchanged.

## Evidence discipline

Internally distinguish:

- `source_fact`: directly stated in the source;
- `user_request`: directly required by the user;
- `adaptation_choice`: a proposed creative change approved by the user.

Do not invent missing source events to make the original seem coherent. When a source gap blocks a safe rewrite, flag it before direction approval. Ordinary prompt detail may be added after approval only when it implements the confirmed plan and does not introduce a new plot fact.

## Quality checks

- The adapted story remains understandable without dialogue.
- Each changed character has one stable identity and function.
- Each recurring prop retains stable appearance, ownership, quantity, and state unless the story changes it.
- Work, trade, rescue, punishment, and reward actions have visible inputs and results.
- The climax is at least as legible and emotionally strong as the source.
- No obsolete role, prop, occupation, location, or motivation survives unintentionally.
- New dialogue expresses already-visible action or emotion; it does not carry essential causality alone.
